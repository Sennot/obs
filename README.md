# ClickSync

Geode-мод для Geometry Dash 2.2081 (Windows). Пока OBS пишет видео, мод записывает каждое нажатие и отжатие
и сохраняет их **с точным временем в видео**. Плагин Click Sampler для Vegas читает этот файл.

Mod for Geometry Dash 2.2081 (Windows). While OBS records, it logs every press/release together with its
exact **video timestamp** into a JSON file for the Click Sampler Vegas plugin.

## Как это работает

1. Мод подключается к OBS по obs-websocket v5 (встроен в OBS 28+).
2. Кадр 0 видео — момент события `RecordStateChanged: STARTED` (OBS подключает энкодеры, следующий нарисованный
   кадр становится первым в файле). Паузы записи (`PAUSED`/`RESUMED`) вычитаются, клики во время паузы получают
   `video_s: null`.
3. Раз в секунду мод спрашивает `GetRecordStatus`. Его `outputDuration` считает кадры, которые уже прошли
   буферизацию звука OBS (до 960 мс) и энкодер, и поэтому отстаёт от картинки на величину, которая меняется от
   сеанса к сеансу (было замерено ~1.02 с). Синхронизировать по нему нельзя (версия 0.2 так и делала, и клики
   стояли на ~1 с раньше). Опросы нужны только чтобы записать в файл эту задержку (`pipeline_lag_ms`), и как
   запасной вариант, если мод подключился к уже идущей записи. Тогда к ним прибавляется время, которое OBS
   дописывал файл после команды «стоп» (`stop_lag_ms`).
4. Каждый вызов `GJBaseGameLayer::handleButton` (в том числе от бота, например xdBot) пишется в журнал:
   нажатие/отжатие, кнопка, игрок, время уровня, кадр xdBot, попытка, практика.
5. Когда запись в OBS остановлена, мод сохраняет `clicksync_ГГГГММДД_ЧЧММСС.json` и копию `latest.json`.
   Если OBS не подключён, файл сохраняется при выходе из уровня (тогда `video_s` будет `null`).

## Настройка

1. В OBS: **Tools → WebSocket Server Settings** → включить сервер (порт 4455). Пароль можно оставить пустым
   или вписать его в настройки мода.
2. Установить `.geode` в папку модов GD.
3. Записывать как обычно. Файлы лежат в `Документы\ClickSampler\Sync\` (папку можно сменить в настройках).

## Формат `clicksync/1`

```json
{
  "format": "clicksync/1",
  "tps": 240.0,
  "obs": { "recording": "D:\\videos\\2026-10-16.mkv", "sync_method": "start", "anchors": 61, "best_rtt_ms": 1.8,
           "pipeline_lag_ms": 1021.4, "stop_lag_ms": 1040.2, "pauses": 0 },
  "attempts": [ { "n": 1, "level": "Name", "level_id": 123, "video_s": 12.0312 } ],
  "events": [
    { "video_s": 15.2041, "level_time": 3.17, "frame": 761, "down": true, "button": 1, "p2": false,
      "practice": false, "attempt": 1, "level": "Name", "level_id": 123 }
  ]
}
```

`video_s` — секунда в видео; `sync_method`: `start` (по моменту старта записи, точный), `anchor` (мод подключился
к уже идущей записи: опросы + `stop_lag_ms`, грубее) или `none`. `pipeline_lag_ms` — на сколько `outputDuration`
OBS отставал от картинки (только для сведения, в `video_s` уже учтено).

## Кадры xdBot

`frame` в файле — номер кадра в нумерации xdBot: `floor(level_time × TPS xdBot) + 1` минус настройка xdBot
**Frame Offset** (не ниже 0). TPS xdBot — его сохранённые `macro_tps` / `macro_tps_enabled`, 240 если TPS выключен.
Шаги физики игры (`GJGameState::m_currentProgress`) для этого не годятся: при 480 шагах в секунду макрос на 240 TPS
пишет кадр 32 там, где счётчик шагов даёт 63. Формула сверена со всеми 18 инпутами `Rela V.gdr`. Сырое число шагов
лежит в `tick`, а реальный TPS игры в `tps`.

## Файлы

Файл сохраняется только если OBS записывал видео (есть `video_s`). Сессии без записи больше не создают файлов и не
затирают `latest.json`. Включить старое поведение: настройка **Save without OBS**. При старте записи и при сохранении
мод показывает маленькое уведомление (настройка **Notifications**).

## Точность

Время берётся в момент, когда игра обработала ввод: ошибка порядка одного кадра видео. Для точной подгонки
в плагине можно сдвинуть всё на фиксированное смещение. Запись лучше начинать, когда игра уже запущена: если мод
подключился к идущей записи, синк будет грубее (`anchor`). Сопоставление с кадрами макроса идёт по `frame` и `level_time`.

## Сборка

GitHub Actions (`.github/workflows/build.yml`): тесты ядра на Linux и сборка `ClickSync.geode` через
`geode-sdk/build-geode-mod`. Артефакт `ClickSync.geode` лежит в результатах запуска.
